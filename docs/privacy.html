Privacy Policy

Last updated: 17 October 2026

KSM Uploader is a personal tool operated by the owner of the KPOP_StageMoments YouTube channel and Instagram account.

Data accessed

The tool uses the YouTube Data API (scope: youtube.upload) and the Instagram API only to upload videos to the owner's own accounts. It does not read, collect, store, or share data about any other person.

Data storage

Access tokens are stored as encrypted secrets and are used only to authorise uploads. No personal data is sold or shared with third parties.

Google API Services

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
